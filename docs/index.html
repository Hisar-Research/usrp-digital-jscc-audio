Joint Source-Channel Coding (JSCC) Audio Decoder

Experimental results comparing audio reconstruction quality across different methods at varying Transmit (Tx) Power levels (31 dB, 33 dB, 35 dB).

Methodology & Bitrate Allocation (3 kbps Total Budget)

  • Original: Uncompressed reference audio.
  • Baseline Encodec (3 kbps): Source coding only (3 kbps Encodec, 0 kbps parity).
  • Baseline Encodec + Conv: Encodec (2.25 kbps) + Convolutional Coding (0.75 kbps parity).
  • Baseline Encodec + LDPC: Encodec (2.25 kbps) + LDPC Coding (0.75 kbps parity).
  • Proposed JSCC: Encodec (2.25 kbps) + Proposed Parity Network (0.75 kbps parity).

Experimental Setup

Over-the-air evaluation using the SDR testbed.
